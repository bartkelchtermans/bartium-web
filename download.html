Thank you for downloading Bartium for Windows!

You need Windows 7 or higher to install, MacOS and Linux coming soon!

How to install

The installation process has a few extra steps because Bartium is not whitelisted yet, we apologize for any inconvenience.
1

Save the file

When your browser asks,
download the file.
2

Open the installer

Doubleclick the file you just downloaded to begin.
3

Click more info

Windows Smartscreen doesn't know Bartium yet and will show a warning. Click more info below the text.
4

Run anyway

A new button will have appeared with the option to run anyway, click it and Bartium will install automatically.
